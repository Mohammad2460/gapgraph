Find the gap behind the gap

Upload a chapter. GapGraph turns it into a live map of concepts, quizzes you, and traces every wrong answer back to the real root cause.

See how it works

The problem

A student fails a question on backpropagation and is told to "study backpropagation again". But the real trouble is often two topics earlier, maybe the chain rule. Re-reading the wrong page doesn't help.

Tests also mix up two very different mistakes: not knowing something, and simply rushing. Treating both the same wastes the learner's time.

How it works

  1. 1

    Upload

    Drop in a PDF, text or code file. Claude reads it.

  2. 2

    Graph

    Concepts and their prerequisites appear as a live, clickable graph.

  3. 3

    Quiz

    Answer 5–10 questions. We note your speed and confidence too.

  4. 4

    Root gap

    Weak concepts light up and the true root gap is traced back.
